Registry: projects built with Bive

Projects built with Bive whose owners opted in: at the end of each session a project sends its human tokens, its agent tokens, its code size, how many writes its guard refused, and which agents and LLMs produced the tokens, nothing else. No name, path, text or IP is kept. A project is listed once it has reported three sessions on two different days.
